Zápis měsíčních hodnot

Otevřete si každý profil a opište počet sledujících a počet příspěvků. Pokud pro dané datum už některou hodnotu máte, můžete pole nechat prázdné. Formulář z toho vygeneruje text, který jen vložíte do souboru manual_entries.json na GitHubu — web se pak aktualizuje sám.

2. Hodnoty

Stačí vyplnit, co je nové — chybějící hodnota se převezme z dřívějšího zápisu.

3. Vygenerovat

  1. Zkopírujte celý text níže.
  2. Na GitHubu otevřete soubor manual_entries.json a klikněte na tužku.
  3. Označte všechno (Cmd+A) a vložte tento text.
  4. Dole Commit changes → potvrdit.

Po uložení na GitHubu se do dvou minut přepočítá i webový přehled.
